### Hola 👋

Actualmente estoy desarrollando una herramienta para leer, graficar y descargar espectros (UV-Vis, con planes para XRD, Raman, IR y XPS). La idea es, básicamente, automatizar lo que en el laboratorio se hace a mano, para que el análisis sea más rápido y reproducible.

Me interesa el rigor y la profundidad conceptual. Disfruto entender los fundamentos antes de aplicar cualquier método, hacer análisis exhaustivos y construir herramientas.

Trabajo principalmente en Linux, con Python para el análisis y el desarrollo de scripts. También uso LaTeX para documentar y HTML/JS cuando necesito llevar algo a la web. Aprendo lo que haga falta según el problema.
